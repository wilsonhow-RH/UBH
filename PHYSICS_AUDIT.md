## Part 1 — Generalizing the symmetry classification of umklapp spots **[DONE]**

Your observation is right, and it is right for a structural reason rather than by
accident: at order 1 the marker set contains, for every overlayer sublattice *s*,
the index vector (n,m,p,r) = (0,0,1,0) — i.e. that sublattice's own first Bragg
star. So the replicas are a *subset* of the order-1 umklapp set by construction.
The distinction you want is therefore not "umklapp vs replica" but a labelling of
every spot by which index vector generates it.

### The scheme

Each candidate spot carries a full index vector **(s; n, m, p, r)** — sublattice *s*
of the overlayer (*s* = 0 primary, *s* > 0 a mirror replica), (n,m) on the substrate
reciprocal basis **b**₁,**b**₂, (p,r) on that sublattice's basis **c**₁,**c**₂. Define
N_sub = |n|+|m|, N_top = |p|+|r|, total order N = N_sub + N_top. Then

| class | condition | meaning |
|---|---|---|
| `substrate` | N_top = 0 | pure substrate Bragg / harmonic |
| `overlayer` | N_sub = 0, s = 0 | pure overlayer Bragg / harmonic |
| `replica`   | N_sub = 0, s > 0 | pure mirror-replica Bragg / harmonic |
| `mixed`     | both > 0 | genuine interlayer umklapp of order (N_sub, N_top) |

This generalizes to any order and to any number of sublattices, and it degrades
gracefully: replicas are simply the s > 0 members of the "pure harmonic" class.

### The part that does not generalize for free

The module generated by two incommensurate 2D lattices is **dense in the plane**.
At sufficiently high order some index vector lands arbitrarily close to any q, so
a position alone does not determine its origin. Two ingredients make the
assignment well posed:

1. **A resolution tolerance.** Spots closer together than the reciprocal-space
   peak width 2π/L (L = the analysis window) are physically indistinguishable.
   The code uses L = 2·FOV in STM-FFT mode and L = 400 Å in LEED mode.
2. **A canonical minimal-order rule.** Within one tolerance ball, the index vector
   of lowest total order N wins; ties break toward the primary sublattice, then
   toward fewer substrate indices. If the *lowest-order* candidates disagree on
   class, the spot is flagged **`origin ambiguous`** and drawn as a grey circle —
   it genuinely cannot be assigned from its position.

Measured ambiguity (STO(100), order ≤ 5, |q| < 3 Å⁻¹):

```
  θ =  0.0°   280 spots,  6 ambiguous      θ = 15.0°   308 spots, 2 ambiguous
  θ =  5.0°   396 spots,  0 ambiguous      θ = 30.0°   306 spots, 2 ambiguous
  θ = 33.0°   416 spots,  0 ambiguous
```

Ambiguity appears exactly at the mirror-symmetric twists (0°, 15°, 30°), where a
replica star maps onto the primary star — the degeneracy is real, not a numerical
artefact.

### The stronger discriminant: intensity, not position

Position-based classification is exhausted at high order; intensity is not.
Measured amplitudes on the STM-FFT (STO(100), θ = 33°, 3× FOV, QC state,
coupling 0.4), normalised to the brightest spot:

```
  class      N    count   median amp   fraction landing on a strong spot
  substrate  1        4      0.4044        100 %
  substrate  2        4      0.0622        100 %
  overlayer  1        4      0.9562        100 %
  overlayer  2        2      0.8754        100 %
  replica    1        8      0.1500        100 %
  replica    2        4      0.1461        100 %
  mixed      2       36      0.0276         44 %
  mixed      3       82      0.0103         34 %
  mixed      4      120      0.0048         23 %
  mixed      5      152      0.0044         12 %
```

Two things fall out. Pure harmonics of *any* class sit on a real spot 100 % of the
time, at every order — so the class label is predictive, not decorative. And the
mixed-umklapp intensity decays monotonically with N, which is the physical reason
a finite order cutoff is legitimate.

The replica class carries a sharper signature still. Measured ratio of replica to
primary Bragg amplitude against the modelled replica weight (= coupling × 0.4):

```
  coupling 0.2 → weight 0.08   measured I_replica/I_primary = 0.080
  coupling 0.4 → weight 0.16   measured                      = 0.160
  coupling 0.8 → weight 0.32   measured                      = 0.320
  coupling 1.0 → weight 0.40   measured                      = 0.400
```

Exact. So in this model the replica-class intensity *is* the order parameter of the
quasicrystalline component, and a measured I_replica/I_primary ratio in real STM
data maps directly onto the coupling strength. [speculation] Whether that mapping
survives a realistic tip-convolution and LDOS weighting is untested here.

### A third, index-free criterion worth adding **[OPEN]**

Classify by **orbit under the point group** instead of by indices: apply the
substrate mirror σ_φ to a spot and ask whether the image is also a spot of the same
intensity. Replica-origin spots map onto primary-origin spots under σ; mixed
umklapp spots map onto other mixed spots of the same order. This is independent of
any index bookkeeping and therefore applies to measured data, where you have no
index vectors. I have not implemented it — say the word and I will.

### What changed in the code

- New `umklapp_indexed()` (returns positions *and* index vectors) and
  `classify_umklapp()` (canonical assignment + ambiguity flag).
- Panel 3's single yellow-×
  set is replaced by four classed marker sets: cyan `+` substrate harmonic, red `+`
  overlayer harmonic, magenta `*` replica harmonic, yellow `×` mixed umklapp, grey
  `○` ambiguous. **Marker area scales as 1/N**, so the order hierarchy is visible
  at a glance.
- Legend names each class with its index signature.

## Part 2 — Audit of the physics modules

### 2.1 Local doping model (`Δn`)

`C_geom = ε₀/z`, `C_total = C_geom·Cq/(C_geom+Cq)`, `Δn = C_total·ΔW/e`.

**The form is right.** Series geometric + quantum capacitance driven by the work
function difference is the standard result for charge transfer across a vdW gap.

**[OPEN — highest-impact numerical issue] The quantum capacitance is ~60× too
small.** The code hardcodes `Cq = 0.01 F/m²`. For monolayer MoS₂ with
g_s = 2, g_v = 2 and m\* ≈ 0.45–0.48 m_e <cite index="14-1">(0.45 m₀ for the lower spin-split conduction band from GW calculations)</cite><cite index="16-1">(0.48 m_e, with g_s = g_v = 2, in first-principles mobility work)</cite>, Cq = e²g_sg_vm\*/(2πħ²) = **0.60 F/m²**; <cite index="13-1">an independent estimate gives ≈ 70 μF/cm² for n-type monolayer MoS₂</cite>, i.e. 0.70 F/m². Consequence, measured:

```
  C_geom(z = 3.35 Å) = 0.0264 F/m²
  Cq = 0.01 → C_total spans 0.00711–0.00741 over z = 3.1–3.6 Å  → contrast  4.0 %
  Cq = 0.60 → C_total spans 0.02363–0.02726 over the same range → contrast 13.3 %
```

With the hardcoded value the interface is *quantum-capacitance limited*, so the
spatial variation of z — the entire point of the panel — is suppressed by a factor
of 3.3. With a realistic Cq the interface is geometry-limited and the map shows the
moiré contrast it is supposed to show. Recommendation: make Cq a per-system
registry entry (MoS₂ ≈ 0.6 F/m², MATBG ≈ 0.002 F/m² is separately defensible since
graphene's DOS vanishes at the Dirac point) and expose it in the UI.

**[OPEN] SrTiO₃ is treated as a metal.** The series chain has only two elements.
STO is a semiconductor with an enormous, field- and temperature-dependent
permittivity, so a space-charge capacitance C_sc should sit in series with the gap
capacitance, and it will dominate at low temperature. For your own MoS₂/STO system
this is the difference between a moiré-modulated doping map and a
substrate-depletion-dominated one. [speculation] I have not estimated the
magnitude; doing so properly needs a Poisson solve in the STO with a
field-dependent ε(E).

**[OPEN] The interface dipole is missing.** Real vdW contacts show a push-back /
pillow dipole that partly screens ΔW, so the bare work-function difference
overestimates transfer.

**[DONE] The `ΔW = 1e-6` fudge is gone.** It existed to avoid a degenerate
colourbar when w₁ = w₂; `safe_limits()` now handles that, and equal work functions
correctly give Δn ≡ 0.

**[NOTE] Sign convention**: w₂ > w₁ ⇒ Δn > 0 ⇒ electrons into layer 2.

### 2.2 Mechanical relaxation solver

**[OPEN — real bug] The solver is zoom-dependent.** `ndimage.laplace()` returns a
*pixel* Laplacian; ∇²Z in Å⁻² is `laplace(Z)/dx²`, and dx = 2·FOV/512 changes by 5×
across the zoom slider. The effective bending stiffness therefore changes by 25×
while the physical system is unchanged. Measured on the same system, same κ = 0.5:

```
  zoom 1×  dx = 0.156 Å   relaxed gap [3.0992, 3.5908]   spread 0.4915 Å
  zoom 3×  dx = 0.469 Å   relaxed gap [3.1070, 3.5407]   spread 0.4336 Å
  zoom 5×  dx = 0.781 Å   relaxed gap [3.1231, 3.4825]   spread 0.3594 Å
```

A 27 % change in the relaxed-gap spread purely from the field of view. Fix is one
line — divide the Laplacian by dx² — but it rescales what κ means, so I left it
for you to confirm.

**[OPEN] "Elastic Bending Rigidity (κ)" is not a bending rigidity.** The force term
is +κ∇²Z, which is the variation of a *tension* energy ½σ|∇Z|². Bending rigidity
would give −κ∇⁴Z (biharmonic). For a monolayer the bending term is the physically
correct one at moiré wavelengths. Either relabel the slider "membrane tension" or
implement the biharmonic operator.

**[OPEN] "vdW Spring Stiffness" is not a vdW interaction.** `F_vdw = −k(Z − Z₀)` is
a Hookean restoring force toward the geometric template, so the equilibrium gap is
whatever Z₀ says it is. There is no attractive −C/z⁴ pressure and no Pauli
repulsion; the only thing preventing collapse under F_elec is this spring and the
hard `clip(1.5, 5.0)`.

**[NOTE] The electrostatic term has the right z-dependence.** F ∝ −1/z² is the
correct fixed-potential capacitor pressure. Its prefactor 0.5(w₂−w₁)² has units of
eV² and is used directly as a force in Å — an arbitrary scale, not a physical one.

**[OPEN — small] Video frames use different physics from the interactive render.**
`iterations = 120 if is_video_frame else 50`. Measured effect is small but real,
and it is converged by ~400:

```
    50 iter → [3.0980+0.0012, 3.5908]     ← interactive
   120 iter → [3.0986, 3.5832]            ← video
   400 iter → [3.0980, 3.5753]
  2000 iter → [3.0980, 3.5746]            ← converged
```

Recommendation: one fixed count (400) for both, or a residual-based stop.

**[NOTE] "Fast Proxy (Algebraic Shift)" adds no spatial physics.** It subtracts the
constant 0.2(w₂−w₁)² from Z₀, so the doping and e-ph maps differ from rigid mode
by a uniform offset only. At the default ΔW = 0.3 eV the shift is 0.018 Å.

**[OPEN] `clip(Z, 1.5, 5.0)` is hardcoded** and silently overrides a user-set
`user_zmax` above 5 Å.

### 2.3 Electron–phonon coupling model

`g(r) = g₀·exp(−(Z − user_zmin)/λ)`, λ default 0.5 Å.

**[OPEN — most substantive physics issue] λ = 0.5 Å contradicts the picture the
FeSe panel is built on.** For a remote interfacial polar phonon the coupling to a
mode of in-plane wavevector q falls off as e^(−qz), so the decay length is 1/q, not
a universal constant. The FeSe/STO replica bands exist precisely because that
coupling is forward-focused: <cite index="12-1">the replicas are complete copies of the main bands, which implies the responsible e-ph interaction is strongly peaked at small momentum transfer</cite>, and <cite index="10-1">the polar oxygen branch peaks at q = 0 with negligible coupling elsewhere</cite>. Quantitatively, <cite index="14-1">a ratio q₀/k_F ≈ 0.1 is required for replica bands to duplicate the primary bands without momentum smearing, with k_F ≈ 0.20 Å⁻¹</cite> — giving q₀ ≈ 0.02 Å⁻¹ and a decay length 1/q₀ ≈ **50 Å**, two orders of magnitude longer than the default. λ = 0.5 Å implies q ≈ 2 Å⁻¹, i.e. zone-boundary phonons, which would smear the replicas out entirely.

Consequence: with λ = 0.5 Å the g-map is a near-binary image of the gap map rather
than a smooth, long-range-correlated field. Recommendation: reparametrise the
slider as q₀ (Å⁻¹) with λ = 1/q₀, default q₀ ≈ 0.02–0.05 Å⁻¹, and note in the UI
that at fixed z this makes g nearly uniform — which is the physical content of
forward focusing.

**[OPEN] `g₀` is referenced to `user_zmin`, not to min(Z_map).** The label reads
"Base Coupling at min gap", but after relaxation Z can fall below user_zmin, giving
g > g₀. Reference it to the actual minimum of the relaxed map.

**[NOTE] g₀ = 80 meV conflates an energy with a coupling constant.** The
experimentally relevant quantity is either the phonon energy — <cite index="17-1">replica bands sit ≈ 90–100 meV below the main bands, attributed to the SrTiO₃ Fuchs–Kliewer phonons</cite> — or the dimensionless λ_eph. 80 meV is close to the former; if that is what is meant, the label should say so.

**Directly relevant to your new system:** <cite index="15-1">replica bands are also observed in 1 UC FeSe/STO(110), with similar separation to the (001) case, indicating the coupling is a generic feature of STO surfaces and interfaces</cite>. So the STO(110) entry added last pass is not just a geometric variant — there is an experimental e-ph benchmark for it.

### 2.4 Misfit dislocation glass

**[OPEN — physics] The displacement field is exactly solenoidal, so it carries no
misfit strain.** `Ux = Σ −k_y sin(k·r+φ)`, `Uy = Σ +k_x sin(k·r+φ)` is
u = ẑ × ∇ψ by construction. Measured on a 200 Å window:

```
  rms div(u) = 7.6e-06     rms curl(u) = 2.2e-02     ratio = 3.4e-04
```

∇·u ≡ 0 means **no local area change anywhere**. But a misfit-dislocation network
is precisely a partition of the interface into commensurate domains — locally
*dilated or compressed* to match the substrate — separated by walls that absorb the
mismatch. The dilatational part is the physics; the model has removed it.
Recommendation: add a curl-free component u = ∇χ with the two amplitudes as
separate controls, or build the field from a soft Frenkel–Kontorova ground state.

**[OPEN] The mosaic wavelength is hardcoded at 120 Å**, independent of twist angle,
lattice mismatch and material. Physically the domain-wall spacing is set by the
competition between interfacial adhesion and overlayer stiffness and tracks the
moiré period. At twists where the moiré period is 40 Å the "glass" imposes an
unrelated 120 Å scale.

**[NOTE] The field is band-limited Gaussian noise, not domains.** Forty plane waves
with σ_k = 0.2 k₀ give a smooth random field; "Experimental Blobs" implies
domains with walls. A soliton-like profile would need a nonlinear ground state.

**[OPEN] The LEED treatment of disorder is not the structure factor of a disordered
lattice.** The glass branch blurs the *intensity* of the undisplaced overlayer with
σ = 0.5 + 4·coupling pixels and scales it by an arbitrary ×3. Static random
displacements should instead produce (i) Debye–Waller suppression
exp(−⟨(G·u)²⟩) of each Bragg peak, which is **G-dependent** — higher-order spots
are suppressed far more — and (ii) a diffuse background carrying the lost weight.
A uniform blur does neither. Since the real-space displaced field already exists,
FFT-ing it directly would be both simpler and correct.

**[NOTE] Panel 2 and Panel 3 describe different disorder in glass mode.** Panel 2
uses actually displaced atoms; Panel 3 uses undisplaced atoms plus a blur.

### 2.5 STM topography model

**[OPEN] Only the coincident registry modulates the apparent height.**
`A_i = 1 + 1.1·exp(−d_co²/2ξ²)`. The hollow and bridge distances are computed for
Panel 1 and then discarded, so Panel 2 sees a two-level (coincident / not) contrast
while Panel 1 shows three registries. Physically the apparent height is a function
of the full stacking.

**[NOTE] It is a constant-height current map, not a topograph.** A linear sum of
Gaussians is ∝ LDOS; constant-current STM height goes as ln(I), i.e. ∝ z-decay of
the LDOS. There is no Tersoff–Hamann treatment, no bias, no tip state. The
colourbar label "Tunneling Density (a.u.)" is honest; the panel title
"STM Topography" slightly overstates it.

**[NOTE] The Z₀ mapping is defensible but should be stated.** `T_total = T_sub ×
T_top` peaks where atoms sit on atoms, and `Z₀ = zmin + T_norm·(zmax−zmin)` maps
that to the *largest* gap — i.e. top-site stacking is sterically repulsive. That is
self-consistent with A_i being brightest at coincident sites, but it is a modelling
choice with no derivation, and it makes the Geometry and Doping panels
anti-correlated by construction.

### 2.6 Scattering (LEED) engine

**[OPEN] Double diffraction is gated by an unrelated control.** In the rigid state
`T_fft_engine = T_sub + T_top` (independent kinematic scattering, no cross terms);
in the QC state it becomes `T_sub × T_top` (which is what generates the umklapp
satellites). But real LEED is multiple-scattering dominated and double-diffraction
spots at G₁ ± G₂ are routine for any incommensurate overlayer, independent of
whether an "interfacial phase state" is switched on. The sum/product switch should
be its own control ("kinematic / include double diffraction"), not a side effect of
the interfacial state.

**[NOTE] No atomic form factors, no Debye–Waller, no interlayer phase factor
e^(iq_z d).** |FFT(density)|² is a cartoon of a kinematic pattern. Fine for the
purpose; worth stating in the UI.

**[NOTE] Nyquist cutoff at q = 4.02 Å⁻¹** (N_FFT = 512 over L = 400 Å) while the
q-Zoom slider reaches 8 Å⁻¹. Beyond ≈ 4 Å⁻¹ the map is blank but markers are still
drawn. N_FFT = 1024 fixes it at ~4× the FFT cost.

### 2.7 Fermi surface panel (FeSe)

**[NOTE] Pocket radii are hardcoded**: r_FeSe = 0.175 Å⁻¹, r_MoS₂ = 0.10 Å⁻¹.
The FeSe value is close to <cite index="14-1">k_F ≈ 0.20 Å⁻¹</cite>. The MoS₂ value corresponds to n ≈ 3×10¹³ cm⁻² for g_s g_v = 4 — plausible for a gated monolayer, but it is not tied to the Δn the doping panel computes. Linking them would make the two panels mutually consistent.

**[NOTE] FeSe M pockets are drawn as circles**; they are elliptical in reality.
**[NOTE] No Γ hole pocket** — which is *correct* for 1 ML FeSe/STO, where the hole
band sinks below E_F. Worth a comment in the code so it is not "fixed" later.
